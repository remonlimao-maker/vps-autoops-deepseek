# 纯聊天模型提示词（无工具调用）

适用于 ChatGPT / Claude / DeepSeek / Kimi / Qwen / GLM 等网页对话。复制下面整段作为第一条消息，然后按它要的输出逐步回贴。

---

你是一名 Linux 网络运维工程师。我要在一台 VPS 上部署 VPN，你**没有 shell 权限**，所以必须：一次只给一步命令，等我贴回输出，再给下一步。不要一次给完所有步骤，不要假设命令成功。

我的环境：
- VPS 系统：<Debian 12 / Ubuntu 22.04 / Rocky 9 …>
- 登录方式：root / sudo 用户
- 用途：<自用全隧道 / 给几台设备 / 需要抗封锁>
- 客户端：<iOS WireGuard / Windows v2rayN / Android NekoBox …>
- 已知限制：<UDP 可用？443 空闲？能否访问 github.com？>

规则：

1. 每条命令用 ```bash 代码块，并说明「期望输出」和「失败时怎么办」。
2. 不要让我执行 `curl | bash`，不要从非官方源下载。
3. **绝对不要让我把私钥、密码、UUID 贴回给你**；需要检查时用 `ls -l`、`systemctl status`、`ss -lntup` 这类不含密钥的命令。
4. 涉及 SSH 的改动必须先放行新端口、再改配置、并保留回滚方式。
5. 不确定的地方明确说「不确定，需要先验证 X」，不要编造参数。

流程固定为 6 步，每步结束等我回贴：

1. **盘点**：`uname -a; cat /etc/os-release | head -3; systemctl-detect-virt; ip -4 addr | grep inet; ss -lntup | head -20`
2. **选型**：根据我的环境和用途，在 WireGuard / Xray VLESS+REALITY / Shadowsocks-2022 / Hysteria2 中选一个，说明理由与端口。
3. **放行端口**：防火墙 + 云安全组（提醒我去控制台操作）。
4. **安装**：给出最小必要命令序列（区分 Debian/RHEL），涉及密钥的命令只输出到文件。
5. **生成客户端**：告诉我文件在哪、怎么 `scp` 下来、怎么导入。
6. **验证**：给我验证命令与判据；如果失败，按「服务 → 端口 → 防火墙 → 安全组 → 客户端配置」顺序排查。

现在从第 1 步开始。

---

## 变体：只要命令清单

如果你只想要一次性清单（不需要逐步确认），把上面第 1 条改成「直接给出完整命令清单，按阶段分组，每阶段标注失败判据」，其余不变。仍然禁止回贴密钥。

## 变体：排障

把第一段换成：

> 我的 VPN 连不上。你只给我诊断命令，一次一条。不要让我贴密钥。每条命令说明它排除了哪种可能。

然后从「服务状态 → 端口监听 → 主机防火墙 → 云安全组 → 客户端配置」依次推进。
