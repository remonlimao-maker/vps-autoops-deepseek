# 向用户收集信息（一次问完）

Agent 读完 SKILL.md 后，**一次性**问完下面这几项，不要逐条挤牙膏。有默认值的可以替用户先填，再让他确认。

## A. 目标机器（先确认这一项）

先问「有没有一台能 SSH 的 VPS」，这决定要不要 Vultr API：

| 情况 | 需要 | 不需要 |
|---|---|---|
| 已有 VPS | IP、SSH 端口/用户、私钥或密码、root 或免密 sudo | Vultr API Key |
| 有 Vultr 账号，没有机器 | Vultr API Key（Read & Write），或先在控制台开一台 | — |
| **连 Vultr 账号都没有** | 先注册 + 充值 + 建 API Key（约 10 分钟） | — |
| 只读规划/写文档 | 无 | 机器、API Key |

第一次用这个 Skill 的 Agent，**不要先问协议**；先确认机器和 API Key，再进协议选择。

| 项 | 必填 | 默认 | 说明 |
|---|---|---|---|
| 主机地址 | 是 | — | IP 或域名 |
| SSH 端口 | 否 | 22 | 改过端口才需要 |
| 登录用户 | 否 | root | 非 root 需要免密 sudo |
| 私钥路径 | 否 | `~/.ssh/id_ed25519` | 已有免密 SSH 时不用给 |
| 是否已在 `~/.ssh/config` 里配好别名 | 否 | 无 | 有别名就直接 `ssh 别名` |

如果用户**还没有机器**：走 `vps-provision`，需要 Vultr API Key（Read & Write）。
**连 Vultr 账号都没有**的，Agent 不能代注册/代付款：把
[`vultr-setup.md`](../../vps-provision/references/vultr-setup.md) 的「注册 → 充值 → 建 Key」
步骤发给用户，等他完成后继续。API Key 只在建机/销毁/快照/查费用时使用；
VPN 装好后删掉 Key 不影响节点运行。

## B. 用途（决定协议与区域）

| 项 | 选项 | 影响 |
|---|---|---|
| 谁用 | 我自己 / 几个人 / 团队 | 客户端数量 |
| 主要目的 | 上 ChatGPT / YouTube / GitHub / 全部 | 区域与后端 |
| 客户端在哪 | 中国大陆 / 境外 | 大陆客户端默认 Hysteria2；确认 UDP 被封才切 REALITY |
| 有没有域名 | 有 / 没有 | 有域名才建议 Trojan |

## C. 策略

| 项 | 默认 | 说明 |
|---|---|---|
| 分流方式 | 国内直连、其余走代理 | 有现成 Clash 配置就直接用 `--template` |
| 配置文件路径 | 自动探测 `./conf.yaml`、`~/Limao/conf.yaml` | 用户有就套用 |
| 是否接受自动选区域/套餐 | 接受 | 不接受才逐项问 |
| 节点密码 | 随机生成（推荐） | 要自己定就提醒：至少 16 位随机，别用 `password123`/生日/手机号/共享弱密码；工具默认随机 |

## D. 边界确认（必须明说）

1. 这台机器**是否专用**？上面有没有其它业务？（决定能否改防火墙、重启服务）
2. 云厂商**安全组**是否已放行 SSH？（未放行会导致连不上，和主机防火墙无关）
3. 是否有**控制台/VNC** 作为最后的退路？（改 SSH 端口前必须确认）
4. 是否接受**按小时计费**（如果走 `vps-provision` 新建）？

## 示例提问（照这个口吻，一次说完）

> 为了帮你配好，我需要这些信息（大部分有默认值，直接说「默认」也行）：
> 1. VPS 的 IP 或域名、SSH 端口（默认 22）、登录用户（默认 root）
> 2. 你本机能不能免密登录？（能的话我直接用现有密钥）
> 3. 主要想用它做什么：ChatGPT / YouTube / GitHub / 全部？
> 4. 客户端在中国大陆吗？（决定用 REALITY 还是也可以走 UDP）
> 5. 有没有现成的 Clash 配置希望我沿用？有就给路径
> 6. 这台机器是专用的吗？有没有其它业务在上面？
> 7. 节点密码用随机生成的，还是你自己定？自己定的话建议 16 位以上随机字符，别用 `password123` 这类共享弱密码。
>
> 拿到这些我就先做只读体检，把要改的东西列给你，等你点头再动手。
